CARA MENAMBAH KARYA KE WEBSITE (tanpa coding)
=============================================

FOLDER 01 "Merch & Clothing Design"  ->  punya halaman showcase sendiri
-----------------------------------------------------------------------
Semua gambarnya ada di folder  images/merch/  :
   cover.jpg      = cover di kartu folder
   scene.jpg      = foto model di halaman showcase (latar sudah bersih tanpa teks)
   logo.png       = logo "M" di kiri atas
   shirt-1.png ... shirt-8.png = tiap desain baju (PNG transparan, yang melayang)
   model-1.webp ... model-8.webp = foto 2 model yang memakai baju nomor yang sama
      (klik baju melayang -> model berganti ke model-N.webp)
Untuk mengganti: upload file baru dengan NAMA YANG SAMA ke folder itu di GitHub
(Add file -> Upload files). File lama otomatis tertimpa.
Tip: kalau punya file desain baju yang lebih tajam (PNG transparan), pakai itu
supaya hasilnya lebih jelas.

Mengubah teks deskripsi yang "diketik": buka index.html di GitHub (ikon pensil),
cari tulisan  data-text=  lalu ubah kalimatnya. Ubah juga kalimat yang sama
persis di dalam tag <p class="sc-type" ...> di sebelahnya.


FOLDER 02 - 06 (Social Media, Branding, Poster, Digital Illustration, Content Video)
-----------------------------------------------------------------------------------
A. SIAPKAN FILE
   - Gambar: simpan sebagai PNG (atau JPG). Beri nama TANPA spasi, huruf kecil,
     misalnya: poster-1.png.
   - Supaya website cepat, kecilkan dulu ukurannya (lebar sekitar 1600 px,
     ukuran file di bawah 1 MB). Bisa pakai squoosh.app (gratis, lewat browser).

B. UPLOAD GAMBAR KE GITHUB
   1. Buka repository website-mu di github.com
   2. Klik folder  images  lalu klik folder  karya
   3. Klik tombol  Add file  ->  Upload files
   4. Tarik (drag) gambar-gambarmu ke situ, lalu klik  Commit changes

C. DAFTARKAN DI js/karya.js
   1. Di repository, buka folder  js  lalu klik file  karya.js
   2. Klik ikon pensil (Edit this file)
   3. Cari folder yang sesuai, misalnya  poster  lalu tulis nama filenya:
          gambar: [
            'poster-1.png',
            'poster-2.png',
          ],
      (nama harus sama persis dengan file yang di-upload;
       gambar PALING ATAS otomatis jadi cover folder)
   4. Untuk video TikTok, tempel linknya di bagian  video:
          video: [
            'https://www.tiktok.com/@usernamekamu/video/1234567890123456789',
          ],
      Cara dapat link: buka videonya di TikTok lewat browser (tiktok.com),
      lalu salin link dari address bar. Pakai link PANJANG yang ada tulisan
      "/video/angka", bukan link pendek (vm.tiktok.com).
      Video paling cocok ditaruh di folder 06 "Content Video".
   5. GANTI juga baris TIKTOK_AKUN di bagian paling atas dengan link
      profil TikTok-mu.
   6. Klik  Commit changes. Tunggu 1-2 menit, lalu refresh websitemu.

HASILNYA
   - Klik folder di website -> terbuka jendela berisi gambar dan video.
   - Setiap video punya tombol "Watch on TikTok" yang membuka videonya.
   - Di folder "Content Video" ada juga tombol "Follow on TikTok"
     yang membuka akun TikTok-mu.


FOLDER 01 - HALAMAN KE-2 "02 Merch" (stiker, tote bag, topi, bucket hat)
------------------------------------------------------------------------
Di dalam folder 01 sekarang ada 2 halaman. Pindah lewat tombol "01 Clothing | 02 Merch" di kanan atas.
Semua gambar halaman 02 ada di  images/merch/goods/ :
   scene.jpg      = foto latar (tanpa teks)
   basket.webp    = keranjang + stiker (bagian yang bergerak/bergoyang)
   sticker-*.webp, tote-*.webp, cap.webp, bucket-hat-*.webp = gambar preview yang muncul saat item diklik
Untuk mengganti: upload file baru dengan NAMA YANG SAMA.
Teks deskripsi: di index.html cari  id="showcase-goods"  lalu ubah data-text= DAN kalimat di dalam <p class="sc-type"> (harus sama persis).
Nama item di pop up: ubah data-gp-title= / data-gp-group= pada baris <button class="gd-hot" ...>.

LANYARD (halaman 02 Merch)
--------------------------
Gambar pop up: images/merch/goods/lanyard.webp (timpa dengan nama yang sama untuk mengganti).
Di index.html cari data-gp-group="Lanyard" untuk mengubah nama/posisi titik klik pada foto latar.
